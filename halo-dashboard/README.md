# Halo Dashboard — Product UI Kit

A finance/crypto dashboard demonstrating the **product-facing** half of the Halo design system. Modeled after the SevenTeen + Velocity references — left sidebar, top bar with greeting, stat row, sparkline chart, asset list, integrations panel.

## Files
- `index.html` — entry point, mounts the dashboard.
- `Sidebar.jsx` — left nav with menu, files, account, plan-meter footer.
- `TopBar.jsx` — search, breadcrumb, notification bell, profile.
- `Stats.jsx` — top stat row with mini sparklines per card.
- `Chart.jsx` — main "Auto Trades" chart card with sparkline + tooltip.
- `Side.jsx` — right-rail Assets list + Integrations panel.
- `Access.jsx` — bottom access-list table.
- `app.css` — kit-specific styles (consumes tokens from `../../colors_and_type.css`).

Open `index.html` to see it.
